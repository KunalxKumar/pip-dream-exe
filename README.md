## 🛠️ The Three Projects

### 1. `PROJECT 01: LULLABY LAB`
- **Concept**: Pip's tiny laboratory for creating dreams through sound.
- **Specification**: Calibrated to **68 BPM** bedtime tempo and **432 Hz** sleep frequencies.
- **Interactive Feature**: Web Audio API music-box synthesizer with individual chime pins (*Cloud, Moon, Star, Beam, Unicorn*) and an automated wind-up lullaby player.

### 2. `PROJECT 02: DREAM DELIVERY ROUTES`
- **Concept**: The primary visual showcase mapping celestial routes from the moon down to sleeping bedrooms.
- **Specification**: Built using **SVG** and **Framer Motion** for zero-latency, high-performance animation.
- **Interactive Feature**: Live packet selector (*Flying Over Cotton Clouds, Endless Hot Cocoa River, Unicorn Starlight Carousel*) and animated route dispatch where Pip travels through moonbeams, cloud shelves, and constellation waypoints.

### 3. `PROJECT 03: NIGHTLIGHT COLLECTION`
- **Concept**: A collection of Pip’s dream nightlights that dispel scary shadows and keep bedroom closets safe.
- **Cards Included**:
  - `NIGHTLIGHT 01: "MOON BEAN"` (Pale amber lunar crescent)
  - `NIGHTLIGHT 02: "STAR PEARL"` (Iridescent starlight bubble)
  - `NIGHTLIGHT 03: "HONEY LANTERN"` (Handheld starfire lantern)
- **Interactive Feature**: `[ TURN ON ]` button that bathes the desktop in glowing ambient starfire and connects directly to the site's night mode.

## 🔊 Audio & Accessibility (Rule 7, 8, 9)

- **Zero Autoplay**: Sound is muted by default. Audio only begins upon direct user interaction.
- **Obvious Mute Controls**: Dedicated `🔊 SOUND ON` / `🔇 SOUND OFF` toggle in the taskbar and Lullaby Lab.
- **Pure Web Audio API**: Zero external audio assets; synthesized music-box chimes and gentle retro beeps.
- **Prefers-Reduced-Motion**: Overrides all heavy animations when enabled.
- **Responsive Layout**: Fluidly tested at `375px`, `390px`, `430px`, `768px`, `1024px`, and `1440px+`.
